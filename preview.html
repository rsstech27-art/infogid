      Как это попадёт на сервер

      Эта страница — только для сборки и визуальной проверки контента. В рабочем гиде тексты и шаги отдаёт бэкенд, а не браузер:

      backend/steps.json { "appTitle": "...", "lockedTitle": "...", "lockedText": "...", "completeButtonText": "...", "steps": [ { "id": "step-1", "title": "...", "text": "...", "blocks": [{ "type": "callout", "label": "...", "text": "..." }], "attachments": [{ "type": "image", "file": "/files/..." }], "children": [ { "id": "step-1-1", "title": "...", ... } ] } ] }
      💡
      Нажми «Показать JSON» ниже — получишь файл в точности такой структуры. Останется положить рядом настоящие файлы (скриншоты, PDF, видео) в папку files/ на сервере и заменить backend/steps.json на выгруженный.

      steps.json

      Скопируй текст ниже и вставь вместо содержимого backend/steps.json. Скриншоты, загруженные здесь для примера, в файле заменены путями вида /screenshots/step-id.png — сами картинки нужно положить на сервер отдельно (см. DEPLOY.md).
