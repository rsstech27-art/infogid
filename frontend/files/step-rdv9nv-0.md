# Команды для гайда «Как подключить Cowork на компьютере»

Копируй команды **отсюда**, а не из основного документа. При копировании из свёрстанного файла длинная строка может разорваться, и команда не выполнится. Здесь строка гарантированно цельная.

**Как копировать:** выдели строку внутри серой рамки → **Ctrl + C** → перейди в PowerShell → **Ctrl + V** → **Enter**.

**Этот файл можно перетащить прямо в чат с Claude** и спросить всё, что непонятно. Например: «что делать, если winget пишет ошибку?» Он ответит по шагам применительно к твоему случаю.

---

## Перед началом

Терминал на Windows называется **PowerShell**.

Открыть: **Пуск** (или клавиша **Win**) → набрать `PowerShell` → **Enter**.

Два правила:

- **Не** запускай «от имени администратора».
- **Не** используй терминал внутри VS Code — нужен обычный PowerShell из меню Пуск.

---

## Команда 1 — Git

Нужен для работы Claude Code. На Windows без него ничего не заработает.

```
winget install --id Git.Git -e
```

Идёт 2–5 минут. Если спросит про соглашения — набери `Y` и Enter.

---

## Команда 2 — Node

Движок для дополнений и интеграций.

```
winget install --id OpenJS.NodeJS.LTS -e
```

**После установки закрой PowerShell и открой заново.** Иначе новые команды не найдутся.

Проверка:

```
node --version
```

Должен появиться номер версии.

---

## Команда 3 — Claude Code

Официальный установщик Anthropic.

```
irm https://claude.ai/install.ps1 | iex
```

Идёт 1–3 минуты. **После установки снова перезапусти PowerShell.**

Затем запусти:

```
claude
```

Откроется браузер — войди в свой аккаунт Claude.

---

## Команда 4 — Python

Понадобится для части интеграций и дополнений.

```
winget install --id Python.Python.3.12 -e
```

**После установки перезапусти PowerShell.**

Проверка:

```
python --version
```

---

## Проверочные команды

Введи по очереди — каждая должна ответить номером версии:

```
claude --version
```

```
node --version
```

```
python --version
```

Если какая-то отвечает «команда не найдена» — перезапусти PowerShell и попробуй снова.

---

## Фразы для чата Claude

Их печатать не нужно — просто копируй.

**Проверка, что Cowork видит папку:**

```
Сделай тестовый md файл и сохрани в проект
```

**Если что-то отвалилось:**

```
почини
```

**Проверка сотрудника:**

```
Ресёрчер, ты тут?
```

**Первое задание:**

```
Составь список из 10 идей для постов по теме [твоя тема] и сохрани в файл idei.md в моей папке
```
